# Skills para la nube de Claude

Una carpeta por categoría. Dentro, un zip por skill (subible uno a uno en claude.ai) y un zip de la categoría completa.

Para subirlos: claude.ai, Configuración, Capacidades, Skills, Subir skill, elegir el zip de un skill.

Ojo: los skills de HyperFrames (video, gsap, three, tailwind, lottie y los adaptadores) necesitan Node, ffmpeg y la CLI `hyperframes`. En el sandbox de la nube pueden funcionar solo a medias.
